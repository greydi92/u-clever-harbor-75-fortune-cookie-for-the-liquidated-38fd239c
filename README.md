# Fortune Cookie for the Liquidated Trader

Built for the [make.fun "Fortune Cookie for the Liquidated Trader" bounty](https://make.fun/bounty/u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c) — a program that writes one fortune-cookie line for a crypto trader who has just been liquidated. Join make.fun with referral code `qgn48q27`: https://make.fun/r/qgn48q27

The fortune it writes:

> You will meet a tall, dark stranger: your liquidation notice, arriving at 3 a.m. with no flowers.

## Run

```sh
node main.ts
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set): one line, 17 words, 97 characters.
